# Модуль 2. Заполнение медицинской документации: ключевые требования

## 1. Значение медицинской документации в ДМС

Медицинская карта пациента является:

- ☑️ юридическим документом при разборе конфликтных ситуаций (вплоть до судебного разбирательства);
- ☑️ первичным документом при формировании финансовых документов по оплате медицинской помощи;
- ☑️ единственным доказательством обоснованности оказанных услуг для страховой компании.

> **Принцип:** эксперт страховой компании не присутствует на приёме. Он оценивает только текст записи. Если логика назначений не отражена в документации — услуга не подлежит оплате.

**Нормативная база:**

- Приказ Минздрава России от 13.05.2025 № 274н — унифицированные формы медицинской документации (с 01.09.2025)
- Приказ Минздрава России от 25.03.2026 № 209н — ведение электронных медицинских документов, подписание УКЭП (с 01.09.2026)

---

## 2. Обязательные элементы записи

Каждая запись в медицинской карте должна содержать следующие блоки:

|Блок|Содержание|Значение для экспертизы|
|---|---|---|
|**Жалобы**|Детально: локализация, интенсивность, динамика|Позволяет определить острое состояние или обострение|
|**Анамнез**|Когда заболел, чем лечился, хронические заболевания|Показывает связь с имеющейся патологией|
|**Объективный статус**|Данные осмотра, измерения, специализированный статус|Подтверждает факт проведения осмотра|
|**Диагноз**|Основной + сопутствующие, с кодом МКБ-10|Ошибка в коде или его отсутствие — основание для снятия|
|**Обоснование назначений**|Причина каждой услуги|Ключевой блок для экспертизы. Без обоснования — снятие|
|**Назначения**|Конкретные услуги, лекарства, рекомендации|Назначение, не зафиксированное в карте, считается невыполненным|

## 4. Принципы построения записи

Запись должна выстраиваться по логической цепочке:

> **Жалобы → Анамнез → Объективный статус → Диагноз → Назначение + Обоснование**

Каждый шаг должен логически вытекать из предыдущего. Назначения, не связанные с диагнозом и жалобами, расцениваются как необоснованные.

**Пример построения записи:**

|Элемент|Содержание|
|---|---|
|**Жалобы**|Сухой кашель 3 дня, температура 38,2°C, боль в правом подреберье (усиливается при кашле)|
|**Анамнез**|Хронический холецистит, последнее обострение 3 месяца назад|
|**Объективный статус**|В лёгких жёсткое дыхание, справа в подреберье болезненность при пальпации|
|**Диагноз**|J06.9 ОРВИ. K81.1 Хронический холецистит, обострение|
|**Назначение + обоснование**|ОАК, биохимия (АЛТ, АСТ, билирубин) — для исключения реактивного гепатита на фоне обострения холецистита; УЗИ ОБП — для оценки состояния желчного пузыря; рентгенография ОГК — для исключения пневмонии; ЭКГ — для исключения кардиальной патологии|

## 5. Типичные дефекты документации

|№|Дефект|Последствие|
|---|---|---|
|1|Отсутствие обоснования назначений|Снятие необоснованных услуг|
|2|Формальное описание жалоб («общая слабость»)|Невозможность определить остроту состояния|
|3|Несоответствие диагноза и назначений|Снятие услуг, не связанных с диагнозом|
|4|Отсутствие динамики при повторных визитах|Снятие повторного приёма|
|5|Отсутствие специализированного статуса|Признание осмотра несостоявшимся|
|6|Отсутствие кода МКБ-10|Основание для снятия|
|7|Использование формулировок без обоснования («проверить», «для профилактики»)|Сигнал для эксперта об отсутствии медицинской логики|

---

## 6. Рекомендуемые формулировки

|Не рекомендуется|Рекомендуется|
|---|---|
|«для профилактики»|«в рамках дифференциальной диагностики основного заболевания»|
|«проверить»|«для уточнения генеза основного заболевания»|
|«оценить динамику»|«в связи с недостаточной эффективностью проводимой терапии»|
|«исключить» (без обоснования)|«в связи с отрицательной динамикой состояния»|

**Пример:**

- ❌ «Назначено УЗИ ЩЖ для исключения патологии»
- ☑️ «Назначено УЗИ ЩЖ для уточнения генеза артериальной гипертензии в связи с недостаточной эффективностью гипотензивной терапии»
