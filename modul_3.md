# Вопросы экспертизы и разбор частых диагнозов
### БЛОК 1. Как работает медико-экономическая экспертиза (МЭЭ)

**Спич врачу:**

> _«Коллеги, прежде чем мы разберем "проблемные" диагнозы, давайте поймем, кто сидит по ту сторону баррикад. Эксперт СК — это не враг, который хочет снять деньги. Это врач, который работает по строгим правилам. Если вы знаете эти правила — вы можете их использовать в свою пользу.»_

#### 1.1. Что проверяет эксперт при МЭЭ

| Что проверяет                          | Как проверяет                                                | Что является основанием для снятия                                                                                                        |
| -------------------------------------- | ------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **Обоснованность назначений**          | Сравнивает диагноз и назначения. Есть ли логическая связь?   | Услуга не вытекает из диагноза (например, УЗИ ОБП при ОРВИ).                                                                              |
| **Соответствие записей в карте**       | Сравнивает записи в карте и предъявленный счет.              | Услуга в счете есть, но в карте нет назначения, обоснования или описания статуса.                                                         |
| **Соответствие программе страхования** | Проверяет, входит ли услуга в программу.                     | Услуга в исключениях, требует согласования или ГП. При этом ни согласования, ни ГП нет.                                                   |
| **Соблюдение лимитов**                 | Проверяет количество процедур/курсов за период.              | Превышение лимита (ФТЛ, ПЦР и т.д.).                                                                                                      |
| **Сроки лечения**                      | Оценивает длительность лечения по диагнозу.                  | Лечение длится дольше средних сроков без обоснования.                                                                                     |
| **Повторные обращения**                | Проверяет, сколько раз пациент обращался по одному диагнозу. | Повторные обращения без новой клинической картины и четко описанной динамики в сравнении с предыдущим приемом в рамках страхового случая. |

---

#### 1.2. «Красные флаги» для эксперта (что привлекает внимание)

| «Красный флаг»                             | Как выглядит                                                                      | Риск                                                                                    |
| ------------------------------------------ | --------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| **«Широкий» скрининг**                     | Назначение большого пула исследований при банальном диагнозе.                     | Выглядит как гипердиагностика, а не мед необходимость.                                  |
| **Повторные исследования без динамики**    | Повторное УЗИ или ЭКГ через 2 дня без изменений состояния.                        | Нет обоснования для повторного исследования.                                            |
| **Отсутствие специализированного статуса** | Невролог не описал неврологический статус, гинеколог — гинекологический.          | Считается, что осмотр не проводился, ранжируется как дефект заполнения мед документации |
| **Триггерные слова**                       | «Проверить», «исключить», «оценить динамику», «для профилактики» без обоснования. | Эксперт видит, что нет четкой клинической логики.                                       |
| **Превышение средних сроков**              | Лечение ОРВИ длится 14+ дней без осложнений.                                      | Эксперт сомневается в необходимости такого длительного лечения.                         |

**Анализ:**

**Почему снимают чаще всего (Дефект оформления документации):**
- Нет детального описания состояния зуба (глубина кариозной полости, реакция на зондирование, перкуссию, термические пробы).
- Нет четкого описания проведенных манипуляций (какой материал, какая анестезия, какой объем работы).
- Нет обоснования для каждого этапа лечения.
- Эксперт не может верифицировать объем оказанной услуги, указанный в счете, с записями в карте.

**Почему снимают (Услуга требовала ГП, не согласовано):**
- Врач не знает, что конкретная услуга требует согласования по программе.
- Анестезия, сложное восстановление зуба, КТ, электроодонтометрия — эти услуги часто требуют ГП в стоматологических программах.
- Врач не проверил программу страхования перед назначением.

**Как избежать:**

| Что делать                          | Как именно                                                                                                                                               |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Детализировать описание лечения** | Записывать все этапы: анестезия (какая, объем), препарирование, медикаментозная обработка, материал пломбы, класс по Блэку.                              |
| **Описать состояние зуба**          | Глубина полости, реакция на зондирование, перкуссию, холод, ЭОД.                                                                                         |
| **Проверять ГП**                    | Перед назначением анестезии, сложного восстановления, КТ — уточнить у администратора либо в МИС в программе страхования, требует ли услуга согласования. |
| **Обосновывать рентген**            | Написать: «для уточнения глубины кариозной полости и состояния периапикальных тканей».                                                                   |

**Готовая формулировка:**

> _«Зуб 36: кариозная полость в пределах дентина, зондирование болезненно по эмалево-дентинной границе, реакция на холод — болезненная, перкуссия безболезненна, ЭОД = 12 мкА. Проведено: инфильтрационная анестезия Sol.Ubistesin 1,8 мл (согласовано по ГП №...), препарирование кариозной полости, медикаментозная обработка 3% H2O2, 0,05% хлоргексидин, наложение изолирующей прокладки (Vitrebond), пломбирование светокомпозитным материалом (Filtek Z250), восстановление контактного пункта, полировка. Прицельная рентгенография — контроль качества пломбирования»_.

**Ключевой вывод:**

> _«Эксперт должен увидеть объем работы. Чем детальнее описание — тем меньше риска снятия. Не жалейте времени на запись — это ваша зарплата.»_

- Врач не проверяет программу страхования перед назначением.

**Почему снимают (Дефект оформления документации):**
- Нет четкого описания состояния пациента: нет температуры, нет данных осмотра носоглотки, аускультации легких.

- ОАК, взятие крови могли проводиться несколько раз в рамках одного страхового случая, что расценивается как гипердиагностика.
- Нет обоснования для внутривенных капельных вливаний — зачем они при ОРВИ?
- Нет динамики при повторных приемах — эксперт не видит прогресса.

**Как избежать:**

| Что делать                  | Как именно                                                                                                                          |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| **Уточнять диагноз**        | Вместо J06.9 писать J06.0 — фарингит, J01.9 — синусит, J20.9 — бронхит. Это показывает, что осмотр был полноценным.                 |
| **Проверять ГП**            | Экспресс-тесты, повторные приемы, капельницы — уточнять необхоидмость согласования.                                                 |
| **Обосновывать назначения** | Для капельницы: «в связи с выраженной интоксикацией, невозможностью перорального приема». Для рентгена: «для исключения пневмонии». |
| **Описывать динамику**      | При повторном приеме: «Состояние с положительной динамикой: температура снизилась до 37,1°C, кашель стал реже, но сохраняется...».  |

**Готовая формулировка:**

> _«Пациент 35 лет, жалобы на сухой кашель в течение 3 дней, температуру 38,2°C, заложенность носа, слабость. При осмотре: гиперемия зева, слизистое отделяемое из носа. В легких жесткое дыхание, хрипов нет. ЧСС 90, АД 120/80. С учетом длительности лихорадки и кашля более 3 дней, а также факторов риска (курение) назначена рентгенография ОГК для исключения пневмонии. ОАК, СРБ для оценки активности воспаления. Экспресс-тест COVID-19 Ag, грипп А/В (согласовано по ГП) для определения этиологии. Рекомендован повторный прием через 3 дня для контроля динамики. Внутривенное капельное введение (согласовано по ГП) в связи с выраженной интоксикацией, невозможностью перорального приема жидкости.»_

**Ключевой вывод:**

> _«При ОРВИ главный враг — неуточненный диагноз и отсутствие ГП. Уточняйте локализацию, проверяйте согласование тестов и капельниц, описывайте динамику. И помните: капельница при ОРВИ без тяжелого состояния — это почти гарантированное снятие.»_

**Анализ:**

**Почему снимают (Услуга требовала ГП, не согласовано):**
- **Физиолечение, массаж, мануальная терапия, ЛФК** — по программам часто требуют согласования, либо ГП. 
- **МРТ, КТ** — почти всегда требуют ГП.
- **Рентгенография** — в некоторых программах может требовать ГП, если это не базовая услуга.
- Врач не проверяет программу перед назначением курса лечения.

**Почему снимают (Дефект оформления документации):**
- **Нет неврологического статуса:** не описаны рефлексы, мышечная сила, чувствительность, симптомы натяжения.
- **Нет обоснования физиопроцедур** — почему именно это лечение, а не другое.
- **Нет динамики** — при повторных приемах не указано, улучшилось или ухудшилось состояние пациента.
- **Нет обоснования МРТ** — не указаны корешковые симптомы, неврологические выпадения.

**Почему снимают (Не соответствует КР):**

- Назначение ОАК, ОАМ при боли в спине без системных симптомов (лихорадка, потеря веса) — не соответствует клиническим рекомендациям.
- Это «лишние» анализы, которые не помогают в диагностике дорсалгии.
- Во многих клинических рекомендациях ФТЛ не относится к блоку лечение, например, в КР Дегенеративные заболевания позвоночника, ФТЛ перенесено в раздел Реабилитация, что гарантированно исключение из программы страхования.

**Как избежать:**

| Что делать                             | Как именно                                                                                                   |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **Описывать неврологический статус**   | Черепные нервы, рефлексы, мышечная сила, чувствительность, координация, симптомы натяжения.                  |
| **Проверять ГП**                       | Физиолечение, массаж, мануальная терапия, МРТ, рентген — уточнять необходимость согласования, требуют ли ГП. |

**Почему это происходит:**

- Врачи не знают, какие услуги требуют ГП по программе.
- Врачи не проверяют программу страхования перед назначением.
- Врачи думают, что ГП можно получить «задним числом» (это не так).

**Как избежать:**
- **Всегда проверять программу страхования.**
- **Запрашивать ГП до оказания услуги.**

#### 3.2. Подробный разбор причины: Дефект оформления документации (106 случаев, 37,1%)

|Диагноз|Количество случаев|Типичные дефекты|
|---|---|---|
|K02.1 (Кариес)|66|Нет детализации лечения, нет описания зуба|
|J06.9 (ОРВИ)|28|Нет обоснования назначений, нет уточнения диагноза|
|M54.8 (Дорсалгия)|10|Нет неврологического статуса|
|I10 (Гипертония)|13|Нет описания криза, нет обоснования анализов|
|E03.9 (Гипотиреоз)|11|Нет объективных симптомов, нет обоснования|
|K04.5 (Периодонтит)|9|Нет детализации лечения|
|K04.0 (Пульпит)|12|Нет детализации лечения|
|J06.8 (ОРВИ)|9|Нет обоснования, нет динамики|

**Почему это происходит:**
- Врачи пишут карту формально, не детализируя.
- Врачи не описывают специализированный статус.
- Врачи не обосновывают каждое назначение.
- Врачи не описывают динамику при повторных визитах.

**Как избежать:**
- **Детализировать каждую запись.** Описывать жалобы, анамнез, объективный статус, диагноз, обоснование назначений.
- **Описывать специализированный статус.** Для каждого врача — свой статус (неврологический, гинекологический, стоматологический и т.д.).
- **Обосновывать каждое назначение.** Кратко: «назначено для...», «в связи с...».
- **Описывать динамику при повторных визитах.** Что изменилось, почему нужен повторный прием.
