# ШПАРГАЛКА ВРАЧА ПО ДМС

## Всё, что нужно помнить на приёме
---
## 🔴 БЛОК 1. СТРАХОВОЙ СЛУЧАЙ: ЧТО ОПЛАЧИВАЕТСЯ

|Это страховой случай?|Да / Нет|
|---|---|
|Острое заболевание|✅ ДА|
|Обострение хронического|✅ ДА|
|Травма, ожог, отравление|✅ ДА|
|Плановое наблюдение хронического|❌ НЕТ|
|Профилактика, скрининг, диспансеризация|❌ НЕТ|
|Реабилитация (без ГП и лицензии)|❌ НЕТ|

> _**Запомните:** Первичный приём оплатится даже при нестраховом случае. Но лечение, назначения и повторный приём — нет._

---

## 🔴 БЛОК 2. ИСКЛЮЧЕНИЯ: ЧТО НЕ ЛЕЧИМ ПО ДМС

| Категория                                | Примеры                                              |
| ---------------------------------------- | ---------------------------------------------------- |
| **Смертельные/особо опасные**            | ВИЧ, туберкулёз, онкология, гепатиты B/C, психиатрия |
| **Хронические (плановое наблюдение)**    | Сахарный диабет, гипотиреоз, гипертония вне криза    |
| **Эстетика и комфорт**                   | Косметология, папилломы, лазерная коррекция зрения   |
| **Альтернативная медицина**              | Остеопатия, гирудотерапия, гомеопатия, УВТ           |
| **Врождённые/наследственные, дефрмации** | Сколиоз, кифоз, врождённые пороки, ДЦП               |

> _**Золотое правило:** Лечение причин и последствий нестраховых заболеваний НЕ оплачивается._

## 🔴 БЛОК 3. ДОКУМЕНТАЦИЯ: ЧТО ПИСАТЬ В КАРТЕ

### Обязательные элементы записи

|Блок|Что писать|
|---|---|
|Жалобы|Детально: локализация, интенсивность, динамика|
|Анамнез|Когда началось, связь с острым состоянием|
|Объективный статус|Данные осмотра + **специализированный статус**|
|Диагноз|**Код МКБ-10 обязателен**|
|Назначения|**Каждое с обоснованием**|
|Динамика (при повторном)|Что изменилось|

### Специализированные статусы (что проверяет эксперт)

|Специальность|Что обязательно описать|
|---|---|
|Невролог|Черепные нервы, рефлексы, сила, тонус, чувствительность, координация|
|Травматолог|Локальный статус: осмотр, пальпация, объём движений, пульсация|
|Гинеколог|Осмотр в зеркалах, бимануальное исследование, выделения|
|ЛОР|Риноскопия, фарингоскопия, отоскопия|
|Офтальмолог|Острота зрения, ВГД, глазное дно|
|Хирург|Локальный статус, симптомы раздражения брюшины|
|Уролог|Пальпация почек, ПРИ, осмотр наружных половых органов|

> _**Правило:** Не описал статус — считай, что не осмотрел. Назначения не обоснованы._

### Запрещённые формулировки

|❌ Не писать|✅ Писать|
|---|---|
|«для профилактики»|«в рамках дифференциальной диагностики»|
|«проверить»|«для уточнения генеза основного заболевания»|
|«оценить динамику»|«в связи с недостаточной эффективностью терапии»|
|«восстановление», «укрепление»|«для купирования острого болевого синдрома»|

## 🔴 БЛОК 4. ФИЗИОТЕРАПИЯ, МАССАЖ, МАНУАЛКА, ИРТ, ЛФК

### Лечение vs Реабилитация

| Если метод в разделе КР «Реабилитация» | НЕ оплачивается, кроме случаев: (1) программа включает реабилитацию, (2) есть ГП, (3) есть лицензия |
| -------------------------------------- | --------------------------------------------------------------------------------------------------- |

### Массаж: диагнозы-ловушки

|Диагноз|Массаж|
|---|---|
|**M54.5** (Боль внизу спины)|✅ ДА|
|**M51.1** (Радикулопатия)|✅ ДА|
|M54.2, M54.8, M53.8, M53.1, M50.3|❌ НЕТ|

### Сколиоз = 100% снятие

> _Если у пациента есть сколиоз II и более степени — НЕ назначать массаж/ФТЛ на эту зону. Даже при ГП._

### Лимиты

| Параметр                            | Норма                        |
| ----------------------------------- | ---------------------------- |
| Перерыв между сеансами              | Не более 2-3 дней            |
| Перерыв между приемом и началом ФТЛ | Не более 7 дней              |
| Курсов за период                    | 1 курс = 1 страховое событие |

### Кто что назначает

|Вид|Кто назначает|
|---|---|
|Физиотерапия|Физиотерапевт|
|Массаж|Лечащий врач или физиотерапевт|
|**Мануальная терапия**|**ТОЛЬКО мануальный терапевт**|
|**ИРТ**|**ТОЛЬКО рефлексотерапевт**|
|**ЛФК**|**ТОЛЬКО врач ЛФК**|

### Этапность

**Со средним чеком:** Лечащий врач → физиотерапевт → 5 сеансов → повторный лечащий врач → закрытие

**Без среднего чека:** Лечащий врач → физиотерапевт → 5 сеансов → повторный лечащий врач → повторный физиотерапевт → продление

## 🔴 БЛОК 5. ДУПЛЕКСЫ БЦА

### Когда НЕ назначать

|Ситуация|Почему|
|---|---|
|Неврологический статус в норме|Нет объективных показаний|
|ГБН, дорсалгия, головокружение без очаговой симптоматики|Не соответствует КР|
|Динамическое наблюдение без ухудшения|Скрининг не оплачивается|
|«Проверить», «исключить» без симптомов|Не страховой случай|

### Когда МОЖНО

|Показание|КР|
|---|---|
|АГ + возраст >50 лет / высокий ССР|КР 62_3|
|ТИА в анамнезе|КР 814_1|
|ИБС без верифицированного атеросклероза|КР 155_2|
|Головокружение + нистагм, атаксия|КР по ВБН|

### Что писать в карте

- «Назначено ДС БЦА для исключения атеросклеротического стеноза у пациентки с АГ и высоким ССР согласно КР 62_3»
- «Назначено ДС БЦА для оценки состояния сонных артерий после перенесённой ТИА согласно КР 814_1»

> _**Помни:** ГП не спасает, если нет медицинских показаний._

## 🔴 БЛОК 6. УЗДГ СОСУДОВ НИЖНИХ КОНЕЧНОСТЕЙ

### Вены: когда НЕ назначать

|Ситуация|Почему|
|---|---|
|ХЗВ без планирования операции|КР 680_2: только клиническое обследование|
|Ретикулярный варикоз (C1)|Не показано|
|Динамическое наблюдение без ухудшения|Скрининг не оплачивается|

### Вены: когда МОЖНО

|Показание|КР|
|---|---|
|Планируется операция (флебэктомия)|КР 680_2|
|Подозрение на тромбофлебит|КР 662_2|
|Тромбоз в анамнезе, контроль|КР 680_2|

### Артерии: когда НЕ назначать

|Ситуация|Почему|
|---|---|
|Нет перемежающей хромоты|КР 155_2: скрининг не показан|
|Атеросклероз без симптомов|Не страховой случай|

### Артерии: когда МОЖНО

|Показание|
|---|
|Перемежающая хромота|
|Ослабление пульсации на артериях стоп|
|Трофические нарушения|

### Что писать в карте

- «Планируется оперативное лечение (флебэктомия). Назначено УЗДГ вен для уточнения тактики операции согласно КР 680_2»
- «Учитывая клиническую картину поверхностного тромбофлебита, назначено УЗДС вен согласно КР 662_2»

## 🔴 БЛОК 7. КАРДИОЛОГИЯ (ГИПЕРТОНИЯ)

| Ситуация                               | Статус                |
| -------------------------------------- | --------------------- |
| В анамнезе: АД >160/100 + симптомы     | ✅ Страховой случай    |
| Плановое наблюдение, коррекция терапии | ❌ НЕ страховой случай |

**Что писать:**

- «АД 180/110, головная боль, тошнота — гипертонический криз. Назначено: ЭКГ для исключения ишемии, консультация кардиолога»
- НЕ писать: «плановое наблюдение гипертонии»

---

## 🔴 БЛОК 8. ЭНДОКРИНОЛОГИЯ (ГИПОТИРЕОЗ)

| Ситуация                                          | Статус                |
| ------------------------------------------------- | --------------------- |
| Плановый контроль ТТГ, коррекция дозы L-тироксина | ❌ НЕ страховой случай |
| Декомпенсация (отёки, брадикардия, слабость)      | ✅ Страховой случай    |

**Что писать:**

- «Резкая слабость, отёчность лица, брадикардия. Состояние расценивается как декомпенсация гипотиреоза. Назначен ТТГ»
- НЕ писать: «контроль ТТГ»

## 🔴 БЛОК 9. ТЕРАПИЯ (ЖДА, ОРВИ)

| Диагноз                 | Что делать                                                                                                                                                                                  |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ЖДА**                 | Уточнить причину. Если меноррагия — гинеколог. Если ЖКТ — гастроэнтеролог<br>Соблюдать этапном - сначала ОАК, потом железо и ферритин<br>Латентный дефицит железа - **нестраховой диагноз** |
| **ОРВИ (J06.9)**        | Уточнить локализацию: J06.0 фарингит, J20.9 бронхит. Обосновать каждое назначение                                                                                                           |
| **Капельница при ОРВИ** | Только при выраженной интоксикации + обоснование + ГП                                                                                                                                       |

## 🔴 БЛОК 10. СТОМАТОЛОГИЯ

|Ситуация|Статус|
|---|---|
|Стоматология в программе|Уточнить объём: что входит, что требует ГП|
|Разрушение зуба >50%|Только эндодонтия. Пломба не оплачивается|
|Протезирование (кроме травмы)|❌ НЕ оплачивается|
|Имплантация|❌ НЕ оплачивается|

> _**Что писать:** Детализировать каждый этап: анестезия, препарирование, материал, класс по Блэку._

## 🔴 БЛОК 13. ЧТО ЗАПОМНИТЬ НАВСЕГДА

| №   | Правило                                                                     |
| --- | --------------------------------------------------------------------------- |
| 1   | **Первичный приём оплатится даже при нестраховом случае.** Но лечение — нет |
| 2   | **Не описал статус — считай, не осмотрел**                                  |
| 3   | **Уточняй диагноз.** J06.9, M54.5, I10 без уточнения — триггер для СК       |
| 4   | **Каждое назначение — с обоснованием**                                      |
| 5   | **Массаж — только M54.5 и M51.1**                                           |
| 6   | **Мануалка, ИРТ, ЛФК — только профильные специалисты**                      |
| 7   | **Перерыв >3 дней — курс прерван**                                          |
| 8   | **ГП не спасает, если нет медицинских показаний**                           |
| 9   | **Сколиоз, кифоз, врождённые аномалии — не лечим по ДМС**                   |
| 10  | **Сомневаешься — спроси администратора или страховой отдел**                |
